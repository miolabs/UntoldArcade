# Your own capture

Drop a mesh and its cooked splat here, in the same space and scale:

- `capture.untold` — the mesh (exported with the Untold Engine exporter or the editor)
- `capture.untoldgs` — the splat (cooked with `untoldengine export` or the editor's Cook sheet)

The demo adds them as a fourth object behind the three synthesised ones. Nothing here is
required; without these files the demo still runs.
